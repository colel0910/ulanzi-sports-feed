# Ulanzi Sports Feed

Compact ESPN score feeds for an AWTRIX NG Ulanzi TC001, generated by GitHub Actions.

## Start
1. Go to **Actions → Refresh compact sports scores → Run workflow**.
2. The workflow should create files in `docs/` for the Eagles, Phillies, 76ers and Flyers.
3. Open `https://raw.githubusercontent.com/colel0910/ulanzi-sports-feed/main/docs/nfl-PHI.json` and confirm it contains JSON.
4. In AWTRIX NG, use **Apps → SportsSuite → Compact scores JSON URL** and enter that URL.

The `state` value is `in` while the team is playing. The scoreboard's own display logic must decide whether to show scores or the regular time. Scores refresh on a roughly five-minute schedule, which can be delayed. ESPN endpoints are unofficial and may change.

This initial version only covers today's games, not future fixtures, detailed stats, standings, news, or full favorite-team rotation. The clock still needs on-device validation. No home IP address or Wi-Fi password belongs in this public repository.
